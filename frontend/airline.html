API 3 – List Tickets

GET /api/airline/tickets?status=

Returns all ticket records across Meridian Air flights. Optional filter: status. Used by Fork0ff to pull airline-side evidence.

API 4 – Ticket Detail

GET /api/airline/tickets/{pnr}

Returns one ticket with fare breakdown (base fare, taxes, total fare) and passenger seat details.

POST /api/airline/tickets

POST /api/airline/tickets

Accepts new ticket records or status updates (e.g., updating a ticket from CONFIRMED to REFUNDED).
