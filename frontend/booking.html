API 1 – List bookings

GET /api/booking/bookings?status=

Returns all booking records (booking ref, customer, airline PNR, route, amount, payment ref, status). Optional filter: status. Used by Fork0ff to pull booking-side records.

API 2 – Booking detail

GET /api/booking/bookings/{bookingRef}

Returns one booking with fare breakdown (base fare, taxes, convenience fee), contact details and booking time. 404 if the reference is unknown.

POST /api/booking/bookings

POST /api/booking/bookings

Accepts new booking records or updates status (e.g., initiating refund or cancelling a ticket).
